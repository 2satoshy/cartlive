# Project Instructions for AI Agent

## GitHub Synchronization
- Remote Repository: `https://github.com/gugunyathi/pnpexpress.git`
- Default Branch: `main`
- Automatically push all code updates and commits to `https://github.com/gugunyathi/pnpexpress.git` after every update using the user's provided Personal Access Token (PAT).
- Always ensure sensitive tokens are cleared from the git remote URL configuration after pushing (`git remote set-url origin https://github.com/gugunyathi/pnpexpress.git`).
